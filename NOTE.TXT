==========================================================================================
THACO AGRI - HỆ THỐNG QUẢN LÝ TÀI SẢN, DỊCH VỤ HOẠT ĐỘNG & THU MUA
HƯỚNG DẪN CÀI ĐẶT & CHẠY ỨNG DỤNG TRÊN MÁY TÍNH CÁ NHÂN (VS CODE & SQL SERVER)
==========================================================================================

1. KIẾN TRÚC HỆ THỐNG (TWO-TIER ARCHITECTURE)
------------------------------------------------------------------------------------------
- Frontend (Client):
  + Thư mục: `src/` (chứa toàn bộ giao diện React 19, Tailwind CSS, Ant Design, Components).
  + Thư mục tài nguyên tĩnh: `public/` (manifest, favicon, icons).
  + File HTML Shell: `index.html`.
- Backend (Server):
  + Thư mục: `server/` (chứa RESTful API endpoints, Database Store, logic nghiệp vụ, T-SQL script).
  + Entry Point khởi chạy: `server.ts`.
- Cơ sở Dữ liệu (Database):
  + Microsoft SQL Server 2019 / 2022 (Database: ThacoAgri_AssetDB).

------------------------------------------------------------------------------------------
2. YÊU CẦU MÔI TRƯỜNG TRÊN MÁY TÍNH (PREREQUISITES)
------------------------------------------------------------------------------------------
Trước khi bắt đầu, hãy đảm bảo máy tính của bạn đã cài đặt các phần mềm sau:
1. Node.js (Khuyến nghị bản LTS v20.x hoặc v22.x):
   - Tải tại: https://nodejs.org
   - Kiểm tra bằng lệnh: `node -v` và `npm -v`
2. Visual Studio Code (VS Code):
   - Tải tại: https://code.visualstudio.com
3. Microsoft SQL Server & Công cụ quản trị:
   - SQL Server 2019 / 2022 (Bản Express hoặc Developer miễn phí).
   - SQL Server Management Studio (SSMS) hoặc Azure Data Studio để quản trị và chạy script SQL.

------------------------------------------------------------------------------------------
3. CÁC BƯỚC CÀI ĐẶT & CHẠY TRÊN VS CODE (STEP-BY-STEP)
------------------------------------------------------------------------------------------

BƯỚC 1: MỞ THƯ MỤC DỰ ÁN
- Mở Visual Studio Code.
- Chọn `File` -> `Open Folder...` -> Chọn thư mục chứa toàn bộ mã nguồn của dự án này.

BƯỚC 2: CÀI ĐẶT THƯ VIỆN PHỤ THUỘC (DEPENDENCIES)
- Trong VS Code, mở Terminal bằng tổ hợp phím: `Ctrl + ~` (hoặc vào menu `Terminal` -> `New Terminal`).
- Chạy lệnh sau để tải và cài đặt toàn bộ package:
  ```bash
  npm install
  ```

BƯỚC 3: TẠO CƠ SỞ DỮ LIỆU MICROSOFT SQL SERVER 2019 / 2022
File script tạo CSDL & nạp sẵn dữ liệu mẫu đã có sẵn ngay tại thư mục gốc:
`ThacoAgri_Database_SQLServer2019.sql`

Cách thực hiện trên máy tính:
1. Mở phần mềm SQL Server Management Studio (SSMS) hoặc Azure Data Studio.
2. Kết nối vào máy chủ SQL Server của bạn (Server name: `localhost` hoặc `.\SQLEXPRESS`).
3. Mở file script SQL:
   - Trong SSMS: Chọn `File` -> `Open` -> `File...` -> Chọn file `ThacoAgri_Database_SQLServer2019.sql` tại thư mục dự án.
   - Hoặc kéo thả file `ThacoAgri_Database_SQLServer2019.sql` vào cửa sổ SSMS.
4. Bấm nút [Execute] màu xanh (hoặc nhấn phím tắt F5 trên bàn phím).
5. Kịch bản sẽ tự động:
   - Tạo CSDL: `ThacoAgri_AssetDB` với bảng mã tiếng Việt Unicode `Vietnamese_CI_AS`.
   - Tạo đầy đủ 15 bảng chuẩn quan hệ (Primary Key, Foreign Key, Unique, Check Constraints, Indexes).
   - Nạp sẵn toàn bộ dữ liệu mẫu thực tế: Đơn vị (Chu Lai, Gia Lai, Campuchia), Nhân sự & Phân quyền RBAC, Kho bãi, Danh mục vật tư, Tài sản định danh (Serial, QR), Tồn kho tiêu hao, Nhu cầu gom PO, Đơn hàng PO, Phiếu đề xuất cấp phát, Ticket sự cố kỹ thuật IT, Lịch sử luân chuyển, Nhật ký kiểm toán.
   - Cuối cùng, script sẽ tự động in bảng tổng kết số lượng bản ghi của 15 bảng để bạn kiểm tra!
6. (Tùy chọn) Bạn cũng có thể tải file này trực tiếp từ trình duyệt khi web đang chạy:
   `http://localhost:3000/ThacoAgri_Database_SQLServer2019.sql` hoặc `http://localhost:3000/api/sql-schema`.

BƯỚC 4: CHẠY HỆ THỐNG Ở CHẾ ĐỘ PHÁT TRIỂN (DEVELOPMENT MODE)
- Trong Terminal của VS Code, gõ lệnh:
  ```bash
  npm run dev
  ```
- Terminal sẽ hiển thị:
  `[THACO AGRI Engine] Server running on http://0.0.0.0:3000`
- Mở trình duyệt Web (Chrome / Edge / Firefox) và truy cập:
  `http://localhost:3000`
- Bạn có thể chỉnh sửa code trong `src/` hoặc `server/`, hệ thống sẽ tự động cập nhật.

BƯỚC 5: ĐÓNG GÓI & CHẠY MÔI TRƯỜNG PRODUCTION (NẾU CẦN)
- Khi muốn biên dịch ra file production:
  ```bash
  npm run build
  npm start
  ```
- Ứng dụng sẽ chạy ở chế độ tối ưu hóa cao nhất.

5. TÀI KHOẢN KIỂM THỬ SẴN TRÊN THANH HEADER (RBAC DEMO)
------------------------------------------------------------------------------------------
Trên thanh tiêu đề (Header) của ứng dụng có thanh chọn nhanh người dùng (Quick Switcher):
1. Nguyễn Văn Hùng - Thủ kho trưởng (`EMP-001` - Vai trò: `THU_KHO`):
   Toàn quyền kiểm soát kho, xuất nhập vật tư, gom PO, duyệt cấp phát.
2. Trần Thị Mai - Chuyên viên Thu mua (`EMP-002` - Vai trò: `THU_MUA`):
   Gom nhu cầu mua sắm, tạo đơn hàng PO, theo dõi giá và nhà cung cấp.
3. Lê Hoàng Nam - Kỹ sư CNTT (`EMP-003` - Vai trò: `KY_THUAT`):
   Tiếp nhận xử lý ticket sự cố, đề xuất phương án kỹ thuật theo 3 kịch bản chuẩn.
4. Phạm Hồng Ánh / Hoàng Minh Đức - Nhân viên (`EMP-004` / `EMP-007` - Vai trò: `CBNV`):
   Tra cứu tài sản cá nhân được bàn giao, lập đề xuất xin cấp mới, báo hỏng thiết bị.
5. Đặng Tuấn Kiệt - Giám đốc CNTT & Quản trị (`EMP-005` - Vai trò: `QUAN_TRI`):
   Quản trị toàn hệ thống, cấu hình CSDL Microsoft SQL Server và xem nhật ký Audit Log.

5.1. QUAN HỆ 3 BẢNG CƠ CẤU TỔ CHỨC: ĐƠN VỊ ➔ PHÒNG BAN ➔ NHÂN VIÊN (CHỨC VỤ & ROLE)
------------------------------------------------------------------------------------------
Ba bảng này được thiết kế ràng buộc toàn vẹn khóa ngoại (Foreign Keys) để đảm bảo logic phần mềm:
1. BẢNG ĐƠN VỊ (`OrganizationUnits`):
   - Cấp cao nhất trong phân cấp pháp nhân (Ví dụ: Tổng công ty THACO AGRI, KLH Gia Lai, KLH Campuchia).
   - Khóa chính: `unit_id`.
2. BẢNG PHÒNG BAN (`Departments`):
   - Trực thuộc một Đơn vị cụ thể (`unit_id`).
   - Ràng buộc: `CONSTRAINT FK_Dept_Unit FOREIGN KEY (unit_id) REFERENCES OrganizationUnits(unit_id)`.
   - Một Đơn vị có nhiều Phòng ban; không thể tạo phòng ban mồ côi.
3. BẢNG NHÂN VIÊN (`Employees`):
   - Bắt buộc liên kết với Đơn vị chi trả lương (`unit_id`) và Phòng ban trực thuộc (`department_id`).
   - Bắt buộc có Chức vụ công tác (`position`, ví dụ: Giám đốc, Trưởng phòng, Kỹ sư IT, Thủ kho trưởng, v.v.).
   - Gán Vai trò hệ thống (`role`: `CBNV`, `THU_KHO`, `THU_MUA`, `KY_THUAT`, `QUAN_TRI`, `QUAN_LY`).
   - Ràng buộc khóa ngoại:
     + `CONSTRAINT FK_Emp_Unit FOREIGN KEY (unit_id) REFERENCES OrganizationUnits(unit_id)`
     + `CONSTRAINT FK_Emp_Dept FOREIGN KEY (department_id) REFERENCES Departments(department_id)`
   - Logic phần mềm: Khi thêm mới nhân viên (User Add), người dùng chọn Đơn vị, hệ thống tự động lọc danh sách Phòng ban trực thuộc đơn vị đó, bảo đảm tính toàn vẹn 100%. Không thể gán nhân viên vào phòng ban thuộc đơn vị khác.

6. XỬ LÝ SỰ CỐ THƯỜNG GẶP (TROUBLESHOOTING)
------------------------------------------------------------------------------------------
1. Lỗi cổng 3000 bị chiếm dụng (Port 3000 is already in use):
   - Mở file `.env` (hoặc tạo mới từ `.env.example`), đổi giá trị `PORT=3001` hoặc `PORT=8080`.
   - Chạy lại lệnh: `npm run dev`.
2. Lỗi PowerShell trên Windows chặn chạy script (ExecutionPolicy):
   - Mở PowerShell với quyền Administrator và chạy lệnh:
     `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser`
   - Nhập `Y` rồi nhấn Enter.
3. Muốn làm sạch CSDL về trạng thái ban đầu:
   - Trên giao diện Web, bấm nút "Khôi phục dữ liệu gốc" (Reset Data) ở góc trên bên phải thanh Header.
   - Hoặc gửi yêu cầu: `POST http://localhost:3000/api/reset`.
